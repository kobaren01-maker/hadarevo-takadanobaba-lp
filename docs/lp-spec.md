# 5. 最重要制作原則

## 5-1. 1ブロック1メッセージ

各ブロックで伝える最重要メッセージは**必ず1つ**。

1つのセクション内で複数テーマを競わせない。

---

## 5-2. 見出しだけでもLP全体が理解できること

ユーザーが文章をほぼ読まずに高速スクロールしても、大見出しだけでストーリーが成立する状態にする。

---

## 5-3. 情報ヒエラルキーを必ず設計する

各ブロックは、

**① 最重要メッセージ
② 証拠・写真・数字
③ 補足
④ 必要な場合のみCTA**

の順で視線が流れるようにする。

### 禁止

- 全部を大きくする
- 全部を太字にする
- 全数字を目立たせる
- 1画面に主役を2つ以上作る
- 大見出しを複数競わせる
- 強調色を乱用する

### スマホ確認ルール

各セクションを1秒だけ見て、

**「このブロックで一番伝えたいことは何？」**

に1つだけ答えられる状態にする。

2つ以上答えが出るなら設計失敗。

# 9. CTA共通仕様

LP内のCTA文言は原則統一。

## CTA

**空き状況を見て予約する**

### 補足

**その場で日時を選んで予約できます（電話・LINEのやり取り不要）**

途中で、

- 相談する
- 詳しく見る
- お問い合わせ

などへ勝手に変更しない。

## ボタンの形・色

当初はLINE公式グリーン＋ピル形状（角丸999px）だったが、これはLINE登録がゴールだった藤沢版の名残であり、LP内予約が目的の現構成ではLINE誘導のボタンだと誤解されやすかった。競合LP（アヴニール）のCTAボタンを参考に、**角の効いた四角形状（border-radius: 10px）**・**ブランドのピンク（`--pink`〜`--pink-deep`のグラデーション）**に変更した。参考LPと異なり、LINEとWEBの2ボタン併記はせず、WEB予約のみの1ボタンで統一する。

## スマホ固定CTAバーの補足コピー

FVのCTAボタンを削除しCTAを固定バーに一本化したことに伴い、固定バーのボタン内に小さく補足コピーを添える（別要素ではなくボタンの2行目として統合）：

**所要時間30秒・24時間受付中**

（Google Apps Script経由のフォーム予約のため、実際に時間帯の制限なく24時間受付できる事実に基づく）

## スマホ固定CTAバーの表示ルール

当初はFV・オファー画像・最終ステップが画面内にある間だけ一時的に隠す仕様だったが、**常時表示に変更**した。ページの最初から最後まで、スクロール方向にかかわらず一切隠れない。

## 口コミ表示

★評価の裏付けとなるGoogle/HPBの評価サマリー画像（`rating-summary.png`）を静止画で提示した上で、その下に実際の口コミ抜粋（横長比率の画像）を横方向に自動スクロールで見せる。この横スクロール部分は「店舗名・プラットフォームを特定して見せる」ものではなく、「実際の声が量として流れている」ことを一瞬で感じさせるための補助表示。個別プラットフォーム（Google/HPB）ごとの実際のスクリーンショットはBLOCK07（予約前の不安解消）で1件ずつ大きく見せる。

# 15. BLOCK 06｜なぜ繰り返すのかを一緒に整理し、肌表面はハーブピーリングで整える

藤沢版では1ブロックに「整理」「ハーブピーリング説明」「初回体験＋レポート」の3テーマを同居させていたが、認知負荷が高いため**3つの独立したセクションに分割**し、それぞれ背景色を変えて区切りを明確にする。1ブロック1メッセージの原則に、より厳密に沿う形にした変更。

## 背景色の割り当て

隣接するBLOCK05（cream）・BLOCK08（pink-pale）とも被らないよう、以下の順で必ず異なる背景色にする（既存パレット内の未使用トーン`--mauve-pale`を活用し、新しい色は追加しない）。

1. `ivory`（BLOCK06-1）
2. `mauve-pale`（BLOCK06-2）
3. `cream`（BLOCK06-3）

## STEPバッジ（3セクション共通）

3つのセクションが「初回来店時に起きることの順番」（相談→施術→レポート）であることが伝わりにくいという指摘があったため、コピーは変えずに各見出しの上へ小さなSTEPバッジ（BLOCK11の`final__step-num`と同じ、ピンクの丸ピル）を追加する：BLOCK06-1「STEP 1」／BLOCK06-2「STEP 2」／BLOCK06-3「STEP 3」。

3セクションはそれぞれ独立した`<section>`で背景色も違うため、標準の余白（上下72px）のままだとSTEP間が間延びして「話が途切れた」ように見えてしまう指摘があった。`.care__note`の下余白を40px→12pxに、各セクション同士が接する側の余白を72px→32pxに詰め、隣接するSTEPどうしの距離感を近づけている。

## BLOCK 06-1｜なぜ繰り返すのかを一緒に整理する

### 1メッセージ
**できたニキビだけを見るのではなく、繰り返す理由を一緒に整理する。**

### ヘッドライン
# まずは「なぜ繰り返すのか」を
# 一緒に整理します

「なぜ繰り返すのか」を`<mark>`で強調（ピンクのマーカー）。指定の2行で改行を固定し、`text-wrap: balance`による自動折り返しには任せない（`.care__headline--fit`）。画面幅によってこの2行が収まらない場合は、フォントサイズを`clamp()`で縮小して収める。ただし縮小しすぎて他のSTEP見出しより極端に小さくならない下限を設ける。

### 内容
実際のカウンセリング写真。今の肌だけでなく、日々の習慣まで確認しながら改善の進め方を考える旨を説明。
