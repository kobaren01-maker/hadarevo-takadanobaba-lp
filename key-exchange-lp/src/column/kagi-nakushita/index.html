鍵をなくした時にまずやること｜家に入れない時の対処法と費用

1. まず安全な場所で落ち着く

鍵がないと気づくと焦ってしまいますが、まずは深呼吸して、安全な場所に移動しましょう。夜間や悪天候の時は、玄関前で待つより、明るいコンビニや駅などで落ち着いて連絡する方が安全です。

スマートフォンの充電が少ない場合は、これからの連絡（店・警察・管理会社・鍵屋）に備えて、なるべく節電しておきましょう。

2. 心当たりの場所に連絡する

最後に鍵を使った時から今までの行動を思い出し、立ち寄った場所に問い合わせます。

  • 職場・学校
  • 立ち寄った店（飲食店・スーパー・コンビニなど）
  • 利用した駅・電車・バス（鉄道会社やバス会社の忘れ物窓口）
  • タクシー（領収書があれば会社名が分かります）

カバンの内ポケットや上着、車の中など、意外な場所から見つかることもあります。もう一度確認してみてください。

3. 警察に遺失届を出す

見つからない場合は、最寄りの交番や警察署で遺失届を出します。都道府県によってはオンラインで届け出ることもできます。届け出ておくと、鍵が拾われて警察に届いた時に連絡をもらえます。

届け出の際は、鍵の特徴（キーホルダーの色や形、本数、ディンプルキーかどうか）を伝えられるようにしておきましょう。

4. 賃貸なら管理会社・大家さんに連絡する

賃貸住宅の場合は、管理会社か大家さんに連絡します。合鍵を預かっていて、開けてもらえる場合があります。

また、賃貸では入居者が勝手に鍵を交換してはいけない契約になっていることが多いため、鍵交換を考えている場合も事前に相談が必要です。夜間や休日は、管理会社の緊急窓口（入居時の書類や物件の掲示に記載されていることが多い）を確認してみてください。

確認すること理由
合鍵で開けてもらえるか鍵屋を呼ばずに済む可能性がある
鍵屋を呼んで開けてよいか物件によっては指定業者がいる
鍵交換のルールと費用負担入居者の紛失は入居者負担が一般的（契約による）

5. 家族・同居人に合鍵がないか確認する

家族や同居人、実家に合鍵を預けていないか確認しましょう。合鍵を持っている人が近くにいれば、それが一番早く、費用もかかりません。

6. 入れない時は鍵屋に鍵開けを依頼する

合鍵がなく、管理会社にも連絡がつかない場合は、鍵屋に鍵開けを依頼します。多くの鍵は壊さずに開けられます。

鍵屋に依頼する時に確認したいこと

鍵開けでは、広告の安い料金で呼んで、現場で高額な料金を請求するトラブルも報告されています。電話の時点で、次の点を確認しておくと安心です。

  • 総額はいくらか（出張費・見積もり費・深夜料金は含まれるか）
  • 見積もり後にキャンセルした場合、費用はかかるか
  • 到着まで何分かかるか
  • 作業前に金額を確定してくれるか

本人確認について

鍵開けの際は、防犯のため身分証による本人確認を求められるのが一般的です。身分証が家の中にある場合は、開錠後に室内の身分証や郵便物で確認する形になりますので、電話で事情を伝えておきましょう。

よくある質問

賃貸で鍵をなくした場合、費用は誰が払いますか？

入居者の不注意による紛失は、入居者の負担になることが一般的です。ただし契約内容によって異なるため、まず管理会社か大家さんに確認してください。

夜中に鍵をなくした場合はどうすればいいですか？

管理会社の緊急窓口や、24時間対応の鍵屋に連絡します。{屋号}は24時間受付しています。

身分証も家の中にある場合、鍵開けはしてもらえますか？

多くの鍵屋では、開錠後に室内の身分証や郵便物で本人確認をする形で対応しています。依頼時の電話で状況を伝えてください。

車の鍵をなくした場合も同じですか？

心当たりへの連絡と遺失届は同じですが、車の鍵は作成方法や費用が異なります。車の鍵トラブルはこちらをご覧ください。
