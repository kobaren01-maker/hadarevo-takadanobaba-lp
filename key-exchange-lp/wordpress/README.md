# WordPress 用の新トップ案（2つの入口）

h-gate.jp の WordPress に、固定ページの**下書き**として入れる新トップ案。公開サイトには影響しない。

| ファイル | 内容 |
| --- | --- |
| `new-top-builder.js` | ページの中身をWordPress標準のブロックで組み立て、下書き（スラッグ `new-top-draft`）として保存・上書きする |
| `new-top.css` | このページだけに効くデザイン。VK ExUnit の「カスタムCSS」欄に入る |

## 構成
1. ファーストビュー：「鍵をなくした・開かない（ご本人）」と「家族・入居者と連絡が取れない（安否確認）」の2つのボタン、電話ボタン、4つの約束
2. ご本人向け（`#self`）：お困りごと、料金表、3つのルール、流れ、賃貸の方へ、鍵交換、まずやること
3. 安否確認向け（`#anpi`）：警察への頼み方と流れ、依頼できる方、料金、管理会社・法人の方へ
4. 選ばれる理由 → 対応エリア → よくある質問 → 最後の電話

車・金庫の鍵は当面対象外なので入れていない。`◯◯円` と赤字の【要確認】は、友人に確認してから埋める。

## 更新のしかた
WordPress の「固定ページを追加」画面（ブロックエディター）を開き、開発者ツールのコンソールでこのファイルの中身を読み込んで `await kmBuildNewTop(new-top.css の中身)` を実行する。同じスラッグの下書きがあれば上書きされる。

## 注意
- サーバーの防御機能（WAF：怪しい通信を止める仕組み）が、CSSのコメント `/* */` を攻撃と見なして保存を止める。スクリプト側でコメントを外してから送っている
- テーマ（Lightning）の見出し帯とパンくずは、このページのCSSで消している
- 公開するときは、現在のHOME（ID 13）と差し替えるか、この下書きをトップに設定するかを決めてから行う
