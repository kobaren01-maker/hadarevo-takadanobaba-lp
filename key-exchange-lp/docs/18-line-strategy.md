# 公式LINEの戦略と導線 2026年11月3日

導線：お客様が「知る → 相談する → 依頼する → また頼む・人に勧める」と進む道すじ。
公式LINE：お店用のLINEアカウント（LINE公式アカウント）。友だちになった人に、メッセージや自動の返信を送れる。

## いちばん大事な考え方：電話とLINEの役割を分ける
鍵屋の依頼の多くは「今すぐ家に入りたい」という緊急の依頼。この人にとっては、電話がいちばん早く確実で、LINEのやりとりを待つ時間はない。LINEを電話と同じ大きさで並べると、迷わせて、かえって依頼が減る。
だから、**緊急は電話、急がない相談と2回目以降はLINE**と役割を分ける。

| 場面 | 主役 | 理由 |
| --- | --- | --- |
| 締め出された・鍵をなくして入れない | 電話 | 到着時間と料金をその場で聞きたい。LINEは待たせる |
| 鍵交換・防犯の相談 | **LINE** | ドアや鍵穴の写真を送れば、来る前に部品と金額の目安が出せる。夜中に思い立って相談できる |
| 電話しにくい状況（夜中、職場、耳が不自由、周りに人がいる） | **LINE** | 文字と写真で相談できる |
| 管理会社・大家さん（くり返し頼む） | **LINE**（＋電話） | 物件名・部屋番号・写真のやりとりが文字で残る。作業報告もLINEで送れる |
| 離れて暮らす家族の安否確認 | 電話（相談はLINEでも） | 緊急性が高い。事前の相談や、あとの報告はLINEが便利 |
| 作業のあと（合鍵、鍵交換、点検、また困ったとき） | **LINE** | 一度頼んだ人が、次も迷わず鍵マッハ24に連絡できる。これが客数を増やすいちばんの近道 |

## LINEで客数が増える3つの仕組み
1. **写真見積もり**：鍵交換の相談を、来る前に写真で受ける。部品と金額の目安が先に分かるので、成約しやすく、現場で揉めにくい。電話では取りこぼしていた「急がないけど気になっている人」を拾える
2. **作業後の友だち追加**：作業が終わって喜んでいる瞬間に、友だちになってもらう。鍵屋は「次に困ったとき、どこに電話したか覚えていない」商売なので、LINEに残っているだけで次の依頼につながる。紹介も「このLINEに連絡して」で済む
3. **作業後の自動メッセージ**：決まった日数のあとに、鍵交換・合鍵・防犯・口コミのお願いを自動で送る。追加の手間なく、2回目の依頼とGoogleの口コミが増える

### 現場 → LINE（いちばん友だちが増える入口）
- 作業後、見積書・領収書と一緒に「LINEのQRコードとGoogleの口コミのQRコード」を印刷したカードを渡す
- スタッフが一言そえる：「次に鍵で困ったときや、合鍵・鍵交換のご相談は、こちらのLINEが一番早いです」
- 友だち追加の特典：「LINEの友だち限定で、次回の鍵交換を◯◯円引き」（金額は友人と決める）
- 口コミのお返しに特典を出すのはGoogleの規約違反。LINEの特典は「友だち追加」に対して出し、口コミとは切り離す

## 返信の決まり（ここが成果を左右する）
- 返信の速さがすべて。**受付中は15分以内に1回目の返信**をする（「確認して◯分以内にお見積もりをお送りします」だけでもよい）
- 誰がLINEを見るかを決める。公式LINEは複数のスタッフで同じアカウントを見られる。夜間の担当も決める
- 写真見積もりは「目安」として出し、「現地で確認して、作業前に書面で正式なお見積もりをお出しします」と必ずそえる（今のサイトの約束と同じ）
- 返信の型（テンプレート）を作り、誰が返しても同じ説明になるようにする

## 料金（LINE公式アカウント）
送るメッセージの数で料金が変わる。友だちが少ないうちは無料のプランで足りる。友だちが増えて自動メッセージの数が増えたら、有料のプランに上げる。最新の料金はLINEヤフーの公式ページで確認する。

## SEO・AI検索とのつながり
- LINE自体はGoogleの順位には直接効かない。ただし、翌日の口コミのお願いでGoogleの口コミが増えると、Googleマップの順位と、AIが「おすすめの鍵屋」を答えるときの材料が増える
- LINEで多かった質問は、サイトの「よくある質問」とコラムのテーマに足す。お客様の実際の言葉は、検索で使われる言葉と同じなので、SEOにも効く

## サイトの準備（済み）
site-builder.js の `LINE_URL` に友だち追加のURL（https://lin.ee/〜）を入れて組み立て直すと、鍵交換・料金表・法人のページの「写真で見積もり」の箱と、画面の下のLINEボタンが出る。空のままなら何も出ない（今は空）。
LINEのボタンは、LINEヤフーが出している「友だち追加ボタン」の決まり（色・ロゴの使い方）に合わせる。

## 公式LINEを作る手順（本人か友人が行う）
1. 「LINE公式アカウント」の申し込みページから、会社のLINEアカウントでログインして作る。アカウント名は「鍵マッハ24」、業種は「生活関連サービス」の中の近いもの
2. スマホに「LINE公式アカウント」のアプリを入れる（返信と通知はこのアプリで受ける）
3. プロフィール：アイコンは鍵マッハ24のロゴ（wordpress/site-icon.png）、背景はFVの写真、説明文は「東京都内・埼玉県南部 24時間受付の鍵屋。鍵開け・鍵交換・安否確認。お急ぎはお電話 070-9186-1366」。電話ボタン・ホームページのボタンを付ける
4. 返信する人を登録する：設定の「権限」から、返信するスタッフを「運用担当者」として招待する。夜間の担当も入れる
5. 通知：アプリの通知を全員オンにする。15分以内の返信は、通知に気づけるかで決まる
6. 応答の設定：「チャット」をオンにし、「応答メッセージ（自動返信）」もオンにする。自動返信は、手が空くまでのつなぎにする
7. あいさつメッセージ・自動返信・リッチメニューを、この文書の文面で入れる（リッチメニューの画像は作れるので依頼する）
8. 友だち追加のURL（https://lin.ee/〜）とQRコードを受け取り、サイトの LINE_URL に入れて組み立て直す
9. 入口ごとにQRコードを分ける（現場のカード、見積書、サイト、ステッカー）。どこから友だちが増えたかを数えるため
10. 現場で渡すカード（LINEのQR＋Googleの口コミのQR）を印刷する。Googleの口コミのQRは、Googleビジネスプロフィールができてから

## 15分以内に返信するための決まり
- 受付中に通知が来たら、作業中でなければ5分以内に開く。作業中なら、手の空いているスタッフが返す
- 1回目の返信は型どおりでよい：「鍵マッハ24です。ご連絡ありがとうございます。内容を確認して、◯分以内にお返事します。お急ぎの場合はお電話（070-9186-1366）がいちばん早いです」
- 写真見積もりは、写真3枚と住所がそろってから出す。足りなければ、何が足りないかを具体的に伝える
- 返信できなかったものは、朝の担当がまとめて確認する
