# 「ご依頼の流れ」の仮の写真：画像生成AI（ChatGPT）用の指示文 2026年11月2日

本物のスタッフの写真が届くまでの仮の画像。届いたら差し替える。
作業員は顔を写さない（手元・首から下・後ろ姿）。実在のスタッフと誤解されないようにするため。

## 使い方
1. ChatGPTで、下の「共通の条件」と「各STEPの内容」を続けて1つの指示として貼る（1枚ずつ作る）
2. できた画像を、下の「確認すること」で点検する。おかしければ「指の本数を自然に」「文字を消して」などと直してもらう
3. 気に入った画像を保存して送ってもらう（正方形1024×1024のまま）。サイト用の240×240のWebPには、こちらで変換する

## 共通の条件（毎回、先頭に貼る）
```
次の条件で、写真を1枚作ってください。

・iPhoneで手持ちで撮ったような、ふつうの写真にする。プロの撮影や広告のような演出はしない
・自然な光。部屋の照明や外の明かりのまま。色は鮮やかにしすぎない
・ほんの少しのざらつきがあり、背景は少しぼけている
・目の高さか、少し上から撮った角度
・場所は日本の住宅（東京の、マンションの共用廊下と金属製の玄関ドア）
・作業員が写る場合は、顔を写さない（手元、首から下、または後ろ姿だけ）。作業着は紺色の無地
・文字、ロゴ、社名、電話番号、看板は一切入れない。紙や画面の文字は読めないようにぼかす
・形は正方形。写したいものを真ん中に置き、まわりに少し余白を残す
・人はわざとらしい笑顔やポーズをとらない。自然な動作の途中を撮ったようにする
```

## 各STEPの内容（共通の条件のあとに続けて貼る）

### STEP1 お電話
```
内容：夜、マンションの共用廊下で、閉まった自分の玄関ドアの前に立ち、困った様子でスマホを耳に当てて電話している30代の女性。体はドアのほうを向き、顔は横向きか少し後ろからで、表情ははっきり見えなくてよい。肩に通勤用のバッグ。廊下の照明だけの明るさ。
```

### STEP2 到着
```
内容：昼間、マンションの共用廊下を、紺色の作業着を着た作業員が工具の入った黒いバッグを持って、玄関ドアの前に歩いてきたところ。首から下か後ろ姿だけを写す。足元は作業靴。
```

### STEP3 書面でお見積もり
```
内容：玄関先で、紺色の作業着の作業員が、クリップボードにはさんだ見積書を、お客様に向けて見せながら説明している手元のアップ。ボールペンで紙の一部を指している。紙の文字は読めないようにぼかす。お客様の手が少し写っていてよい。顔は写さない。
```

### STEP4 サインをいただいて作業
「鍵穴に細い工具を差し込む」と書くと、ピッキング（不正な解錠）と判断されて生成を止められた（11/2）。ドアが開いている・昼間・お客様がいる、という正規の作業と分かる場面にする。

案A：鍵交換の作業
```
内容：昼間、開いた状態の金属製の玄関ドアの側面で、紺色の作業着の作業員が、プラスドライバーでドアの側面の金属の板のネジを外している手元のアップ。鍵の部品の交換作業の途中。足元に工具箱と、新しい鍵の部品が入った箱が置いてある。顔は写さない。
```

案B：作業後の確認（説明文「一緒に傷がないか確認」に合う）
```
内容：昼間、開いた状態の金属製の玄関ドアの前で、紺色の作業着の作業員が、ドアの鍵まわりを指さしながら、お客様と一緒に傷がないかを確認している場面。作業員は首から下、お客様は後ろ姿。作業員の手には鍵を持っている。顔は写さない。
```
それでも止められたら、「鍵」を「玄関ドアの金具」に言い換える、工具の記述を消す。

### STEP5 お支払い
```
内容：玄関先で、お客様がスマホを小型のカード決済の端末に近づけて支払っている手元のアップ。紺色の作業着の作業員が端末を持っている。画面は見えない角度にし、文字や数字は写さない。顔は写さない。
```

## 確認すること
- 指の本数や形が自然か（AIの画像は指がおかしくなりやすい）
- 文字・ロゴ・数字が入っていないか（入っていると崩れた文字になりやすい）
- 鍵穴やドアの形が、日本の住宅として不自然でないか
- 作業員の顔が写っていないか
- 写真というより絵やCGに見えないか（見える場合は「もっとふつうのスマホ写真のように」と直してもらう）
- 5枚の作業着の色・雰囲気がそろっているか
