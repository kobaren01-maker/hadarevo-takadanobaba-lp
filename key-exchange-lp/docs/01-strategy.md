# 鍵トラブル（鍵開け・鍵交換）LP 方針書 v0.1

> 現行LP（h-gate.jp）を全面リニューアルする。本書は「誰に・何を・どの順で伝えるか」と「広告／SEO／AIOをどう両立して育てるか」の土台。
> `【要確認】` は事業者（ご友人）に確認して埋める項目。数字・実績は**実在するものだけ**を載せる（景品表示法・広告審査の両面で必須）。

---

## 1. 前提：このページに来る人

| 項目 | 内容 |
| --- | --- |
| 状況 | 鍵をなくした／閉め出された／鍵が回らない。**今まさに玄関前や車の横にいる**ことが多い |
| 端末 | ほぼスマホ（片手・屋外・夜間・バッテリー残量少なめを想定） |
| 心理 | ①焦り「早く入りたい」②不安「いくら取られる？」「怪しい業者じゃない？」③迷い「警察？管理会社？鍵屋？」 |
| 行動 | 検索 → 広告/上位を2〜3件開く → **料金と到着時間が一目で分かる所**に電話。比較時間は数十秒〜数分 |
| 離脱要因 | 料金が「◯円〜」だけで総額が見えない／電話番号が探しにくい／会社の実体が見えない／ページが重い |

**結論：「3秒で“ここに電話して大丈夫”と思える」ことが最優先。**
情報量は多く持つ（SEO・AIO・比較検討層のため）が、ファーストビューと固定CTAで“今すぐ層”を即座に電話へ流す二層構造にする。

### 業界背景（差別化の核）
鍵開けは「◯◯円〜」の低価格広告で呼び、現場で高額請求するトラブルが国民生活センター等で繰り返し注意喚起されている。
ユーザーは**「安さ」より「最終的にいくらか分かること」**を求めている。ここを正面から打ち出す。

## 2. ポジショニング（ひと言で）

> **「作業前に“総額”を確定。納得してからしか作業しない、地元の鍵屋」**

伝える約束（ブランドプロミス）を4つに固定し、FV・広告文・GBP・記事末尾すべてで同じ言葉を使う（AIOでのエンティティ認識にも効く）。

1. **総額表示**：出張費・見積もり費・作業費込みの金額を作業前に提示【要確認：出張費／深夜割増の有無】
2. **キャンセル無料**：見積もり後に断っても0円【要確認】
3. **最短◯分で到着**：拠点からの実到着時間を地域ごとに明記【要確認】
4. **顔の見える事業者**：代表・スタッフの顔写真、所在地、固定電話、資格を明示

※「業界最安」「No.1」「絶対」等の最上級・断定表現は根拠資料がない限り使わない。

## 3. ゴール設計とKPI

| 種別 | アクション | 位置づけ |
| --- | --- | --- |
| 主 | **電話タップ** | 緊急層のほぼ全て。最重要 |
| 副 | LINE（写真を送って見積もり） | 「電話しづらい」「深夜で声を出せない」「急ぎでない交換」層 |
| 副 | Webフォーム | 鍵交換・防犯相談など予約型 |

- KPI：CVR（電話タップ率）、CPA、**実通話数と成約率**（タップ≠通話。コールトラッキング推奨）
- 計測：GA4イベント `tel_click` / `line_click` / `form_submit`、Google広告の電話コンバージョン（ウェブサイト上の電話番号へのコール）を設定

## 4. 流入チャネル別の役割

| チャネル | 役割 | このLPでの対応 |
| --- | --- | --- |
| リスティング広告 | 今すぐ層の即獲得 | FV・料金・電話を最上部に。広告グループ別にFV見出しを出し分け（`?type=car` 等のパラメータ、フェーズ2） |
| Googleマップ（GBP） | 「近くの鍵屋」系の最大流入源 | NAP（屋号・住所・電話）をLPと完全一致させる。口コミ獲得を運用に組み込む |
| 自然検索（SEO） | 中長期の低CPA獲得 | サービス別・エリア別ページ＋コラムで網を張る |
| AI検索（AIO / AI Overviews、ChatGPT等） | 「鍵 なくした どうする」等の質問への引用元になる | 質問形式の見出し＋結論先出し＋構造化データ＋一次情報 |

> 鍵屋はGoogle広告で事業者確認を追加で求められることがある業種。出稿前に審査書類（事業者情報・所在地確認）を準備しておく。

## 5. サイト構成（育てる前提の設計）

LP単体ではなく、**トップ＝LP兼ハブ**として下層を増やしていく構成にする。

```
/                         … トップ兼LP（本骨組み：src/index.html）
/price/                   … 料金表（詳細・鍵種類別・時間帯別）
/service/
  ├ kagiake/              … 鍵開け（家・玄関）
  ├ koukan/               … 鍵交換・シリンダー交換
  ├ funshitsu/            … 鍵をなくした時（紛失対応の総合ページ）
  ├ car/                  … 車・バイクの鍵（インロック・スマートキー作成）【要確認：対応可否】
  ├ kinko/                … 金庫開錠【要確認】
  ├ bouhan/               … 防犯・補助錠の取り付け
  └ ...（郵便ポスト、スーツケース、合鍵作製 等）
/area/
  ├ {市区町村}/            … エリア別ページ（到着目安・事例・地域情報を個別に書く）
  └ ...
/case/                    … 作業事例（日付・エリア・鍵種類・所要時間・金額）
/column/                  … お役立ち記事（日々更新）
/company/                 … 会社概要・代表挨拶・資格
/contact/  /privacy/
```

- **エリアページは中身を地域ごとに変える**（到着目安・その地域の作業事例・よく出るマンションの鍵種類など）。地名だけ差し替えた量産ページは評価されない。
- **作業事例はCMSで1件ずつ投稿**できるようにする。事例は「一次情報」であり、SEO・AIO・信頼性すべてに効く最強の資産。
- CMSは**WordPress推奨**（日々の記事・事例更新を本人が行う前提）。本リポジトリの静的HTMLは「構成とデザインを合意するための骨組み」で、合意後にテーマ化する。
- ドメインは**h-gate.jpを継続**（既存の被リンク・運用歴を活かす）。リニューアル時に旧URLから301リダイレクトを設定。

## 7. デザイン方針

- **スマホファースト**（375px基準）。PCは中央寄せ＋サイド余白で十分。
- 色：**信頼の紺（ネイビー）＋行動のオレンジ（電話ボタン専用）**＋白基調。赤は「注意」にだけ使う（煽りに見えるので多用しない）。
- 文字：本文16px以上、料金は太く大きく。屋外の直射日光でも読めるコントラスト（WCAG AA以上）。
- 電話ボタン：高さ56px以上、親指が届く画面下部に固定。番号をボタン内にも表示（「どこに掛かるか」が見えると押しやすい）。
- 写真：**実写のみ**（スタッフ、作業車、作業風景、実際の鍵）。フリー素材の外国人モデルは信頼を下げるので使わない。
- 速度：LCP 2.5秒以内目標。FV画像は1枚・WebP・軽量化、Webフォントは使わずシステムフォント。
- 煽り表現（点滅、「今すぐ！！」の連打、カウントダウン）は使わない。**落ち着いたトーンそのものが安心感**になる。

## 8. SEO / AIO の方針

### 8-1. 技術面（骨組みに実装済み）
- `title` / `meta description` にメインKW＋地域＋約束（総額・24時間）
- 見出し階層 h1→h2→h3 を厳守。h2に検索KWを自然に含める
- 構造化データ（JSON-LD）：`Locksmith`（LocalBusiness）、`FAQPage`、`BreadcrumbList`、記事には `Article`＋著者
- 料金表・FAQ・エリアは**テキストで記述**（画像の中の文字は検索にもAIにも読まれない）
- NAP（屋号・住所・電話）をフッター・会社概要・GBP・各種ポータルで**一字一句一致**

### 8-2. AIO（AI検索に引用される）ための書き方
1. **見出しを質問形にし、直下の1〜2文で結論を言い切る**
   例）「鍵開けの料金はいくら？」→「玄関の一般的な鍵なら◯円（出張費込み・税込）です。」
2. **数字・条件を具体的に**（◯分、◯円、対応時間、対象の鍵種類）
3. **一次情報**：自社の作業事例・実際にかかった時間・現場写真・代表の経験談
4. **誰が書いたか**：記事に監修者（代表・資格）を明記、プロフィールページへリンク
5. **更新日を表示**し、料金改定時は必ず更新
6. 外部での言及（GBP口コミ、地域ポータル、業界団体名簿）を増やす＝AIが「実在する信頼できる事業者」と認識する材料

### 8-3. 記事運用（日々の更新）
- キーワード設計 [`02-keywords.md`](02-keywords.md) の「コラム」列から、**月8〜12本**を目安に公開
- 1記事1テーマ。結論→理由→手順→費用→「困ったら当社へ」の型で統一
- 作業事例は**週2〜3件**投稿（写真＋エリア＋鍵種類＋時間＋金額）。これがエリアページ・サービスページに自動で並ぶ設計にする
- 月1回：Search Consoleで表示回数が多いのに順位が低い記事をリライト

## 9. 法令・審査まわりの注意

- **景品表示法**：「◯円〜」表記は最低料金が適用される条件を併記。二重価格・根拠のない「最安」は不可
- **特定商取引法**：訪問を伴う役務のため、契約時の書面交付等に注意【要確認：現行の運用】
- 鍵開けは**本人確認（身分証）を必須**と明記（防犯上の配慮＝信頼にもつながる）
- 口コミは実在のもののみ。掲載許諾を取る

## 11. ヒアリングシート（ご友人に確認すること）

**基本情報**
- [ ] 屋号・会社名／代表者名／所在地（拠点）／電話番号（固定・携帯）／LINE公式アカウントの有無
- [ ] 受付時間・作業時間（本当に24時間対応か、深夜は受付のみか）
- [ ] 対応エリア（市区町村単位）と各エリアへの実際の到着目安

**料金**
- [ ] 鍵開け（玄関・一般／ディンプル／補助錠／車／金庫）の料金
- [ ] 鍵交換（シリンダー種類別）の部品込み料金
- [ ] 出張費・見積もり費・深夜早朝割増の有無と金額
- [ ] 見積もり後キャンセル時の費用
- [ ] 支払い方法（現金・カード・QR決済・後払い）

**信頼材料**
- [ ] 創業年・累計作業件数（根拠あるもの）
- [ ] 保有資格（防犯設備士、錠前技師など）、加盟団体
- [ ] Google口コミの件数・評価、掲載許諾が取れる声
- [ ] 作業事例として使える写真（ビフォーアフター、作業中）
- [ ] 保証（交換後の不具合対応など）

**運用**
- [ ] 現行サイトのCMS・サーバー・ドメイン管理者
- [ ] 記事を書く人・頻度（本人が書く／代筆）
- [ ] 広告予算感、Googleビジネスプロフィールの状況
