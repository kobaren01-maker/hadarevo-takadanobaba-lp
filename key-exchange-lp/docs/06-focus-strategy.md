# 勝ちに行く分野の選定（自然流入メイン） v0.1

> 2026年10月時点のWeb検索による調査。検索ボリュームの実数は未取得（キーワードプランナー等で要確認）。

## 前提
- 競合は広告で安く大量に集める方向。こちらは**自然流入（SEO・AI検索・Googleマップ）での問い合わせ**をメインにする
- 即効性より、勝てる確率の高さを優先
- 候補は「鍵の紛失」と「安否確認の鍵開け」

## 結論
**自然検索で最初に取りに行くのは「安否確認の鍵開け」。**
「鍵の紛失」は自然検索の全国戦ではなく、**Googleマップ（GBP）と地域の作業事例**で取る。

## 1. 鍵の紛失

| 観点 | 評価 |
| --- | --- |
| 需要 | 大きい。毎日発生する |
| 競合 | **非常に強い**。比較・マッチングサイト（ミツモア、生活110番、くらしのマーケット）と大手チェーン（鍵の110番救急車、鍵猿、鍵の本舗、キーレスキュー、アンロック等）が、エリアページとコラムを大量に持っている |
| 価格競争 | 激しい。「1,500円〜」「1,980円〜」など安い入口価格の表示が多い |
| 検索者の行動 | 焦っていて、地図や上位の数件にすぐ電話する。じっくり読まない |
| 自然検索での勝ちやすさ | **全国規模のキーワードは低い**。ただし「地域名＋鍵開け」と**Googleマップの上位3件**は、地元業者でも十分勝てる |

→ 紛失は「サイトを読ませて勝つ」より、**マップ・口コミ・地域の作業事例で勝つ**分野。

## 2. 安否確認の鍵開け

| 観点 | 評価 |
| --- | --- |
| 需要 | **増え続けている**。警察庁の集計では、2024年に自宅で亡くなった一人暮らしの人は全国で76,020人（約76%が65歳以上）。内閣府の推計では、死後8日以上たって見つかる「孤立死」が2024年21,856人→2025年22,222人と増加。東京23区の65歳以上の孤独死は、2020年時点で9年連続増加 |
| 競合 | **薄い**。専門のページを持つ鍵屋はごく一部で、多くはブログ1本やFAQの1項目程度。「安否確認」の情報記事は警備会社・管理会社・法律事務所が書いていて、**現場の鍵屋が書いたものが少ない** |
| 単価 | 高い（現場での実感どおり）。ある都内業者の表示は15,400円〜 |
| 依頼者 | 離れて暮らす家族、管理会社・大家、ケアマネジャー・地域包括支援センター、社宅の単身社員を抱える会社 |
| 検索者の行動 | 不安だが、紛失ほど一刻を争う焦りではない。**手順や費用、警察とのやりとりをきちんと調べてから依頼する**＝読ませるページが効く |
| 繰り返しの依頼 | 管理会社・介護事業者・会社は、一度信頼されると**継続して依頼をくれる**（法人の取引先になる） |
| AI検索との相性 | 良い。「親と連絡が取れない どうする」「安否確認 警察 鍵開け 流れ」のような質問型の検索が多く、手順を書いた記事が引用されやすい |
| 自然検索での勝ちやすさ | **高い** |

### 注意点
- **手順と権限**：管理会社や大家には鍵を開ける法的義務はない。実務では親族や管理会社の依頼のうえで、警察の立ち会いのもと開けるのが基本。依頼者の本人確認と続柄の確認、警察との連携をページで明確にする
- **トーン**：人の生死に関わる場面。派手なデザインや「安い・早い」の煽りは逆効果。落ち着いた、誠実な見せ方にする（トップのLPとは別の雰囲気でよい）
- **現場の負担**：開けた先でご遺体が見つかることもある。スタッフの対応方針と、その後の連絡先（警察の指示に従う等）を事前に決めておく
- **プライバシー**：事例は個人が特定されない形で、依頼者の許可を得て載せる

## 4. 進め方の案
1. **安否確認の専門ページ**（h-gate.jp 内に `/anpi/`）を作る。家族向け・管理会社向け・会社向けで入口を分ける
2. 情報記事を積み上げる（例）
   - 親と連絡が取れない時にまずやること｜警察に相談する目安
   - 安否確認の鍵開けの流れ｜警察・管理会社・鍵屋の役割
   - 管理会社が鍵を開けてくれない時はどうする？
   - 安否確認の鍵開け費用は誰が払う？
   - 社員と連絡が取れない時、会社ができること
   - 離れて暮らす親のために今できる備え（合鍵の預け先、見守りサービス）
3. 管理会社・介護事業者向けの法人ページを作り、地域の管理会社に案内する
4. 紛失は、Googleビジネスプロフィールの整備、口コミ集め、既存の作業事例39件のタイトル修正（地域名入り）で並行して取る

## 5. 決める前に友達に確認したいこと
- 直近6〜12か月の**安否確認と紛失それぞれの件数・平均単価**
- 安否確認の**依頼者の内訳**（家族／管理会社／警察経由／会社）
- 安否確認の**作業の流れ**（警察の立ち会いの有無、必要書類、所要時間、料金の決め方）
- 管理会社などとの**継続的な取引**があるか
- 開けた先で亡くなっている方を見つけた経験と、その時の対応
