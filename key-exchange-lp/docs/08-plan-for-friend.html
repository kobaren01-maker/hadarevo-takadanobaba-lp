鍵マッハ24（株式会社hgate）向け

鍵マッハ24 自社集客プラン

2026年10月作成（10月27日更新）。元請けからの仕事で売上を守りながら、自社に直接依頼が来る道を、お金のかからない順に育てるための方針です。

結論

  1. 元請けの仕事は続ける。今の売上の土台です。自社集客は、元請けの代わりではなく「上乗せ」として始めます。
  2. 元請けとぶつからない場所から攻める。Googleマップ、赤羽を中心とした北側だけの地域広告、大家・不動産屋、警察との信頼。元請けが広告を出している「鍵開け」「緊急」のような言葉は買いません。
  3. お金のかからない順に進める。まず0円でできること（マップ登録、依頼の記録、作業事例）。次に月数万円の広告テスト。結果を見てから広げます。
  4. 判断の物差しは1つ。「自社で1件取る費用」が「元請けに払う1件あたりの手数料」より安ければ、自社で取るほうが得です。言葉ごとにこの比較で広げるかやめるかを決めます。
  5. 実測で、安くて量がある言葉が見つかった。東京都で「鍵交換 費用」は月1,000〜1万回、1クリック146〜504円。「鍵屋 赤羽」は245〜1,061円。一方「鍵屋 緊急」は1,639〜4,390円でした。同じ鍵屋の言葉でも、選び方で1件の費用が約9倍変わります。

今の状況

鍵マッハ24は今、自社で集客をしていません。元請け（駆けつけサービスの会社）がYahoo!広告などで「緊急 鍵 開け」のような言葉に広告を出し、入った仕事を振ってもらっています。作業員は10数名が都内各地で待機していて、拠点は赤羽です。

元請けの仕事の良いところ

  • 広告費がかからない
  • 仕事が安定して来る
  • 都内全域の仕事を受けられる

元請けだけに頼る弱いところ

  • 1件ごとに手数料を払っている
  • 件数も料金も元請けしだい
  • お客様が「鍵マッハ24」を覚えない。口コミも紹介も自社に残らない
先に確認したいこと：元請けとの契約で禁止されていること（元請け経由のお客様への名刺・ステッカー配布、直接の受注、同じ地域での集客など）。ここが分かるまでは、元請け経由のお客様には何もしません。

狙う 安い少額で試す買わない 高い・元請けとぶつかる

この金額と、元請けに払っている1件あたりの手数料を比べます。たとえば手数料が1件1万5千円なら、「鍵交換 費用」と「鍵屋 赤羽」は自社で取るほうが得で、「鍵開け」「鍵屋 緊急」は元請けに任せるほうが得、という判断になります。

元請けとぶつからない4つの場所

お金のかからない順に並べています。

  • Googleマップ

    0円

    赤羽の自宅を拠点に「出張型の業者」として登録します（住所は表示しません）。マップの順位は拠点からの距離で決まるので、北区・板橋区・足立区など北側で強く出られます。口コミが増えるほど強くなります。

  • 北側だけの地域広告

    月3万〜5万円から

    広告を出す地域を赤羽まわりに絞り、「鍵交換」「鍵屋＋地名」のような安い言葉だけに出します。元請けが出している「緊急」「24時間」の言葉には出しません。

  • 大家・不動産屋・管理会社

    0円（時間）

    入居者の鍵の紛失、退去時の鍵交換、入居者と連絡が取れないときの安否確認。検索しない相手なので、北側の不動産屋から直接案内します。一度取引すると繰り返し依頼が来ます。

  • 警察・安否確認

    0円（時間）

    安否確認は単価が高く件数も多い仕事です。依頼者は多い順に個人のお客様、警察、大家。警察の立ち会いに慣れていること、作業報告書をきちんと出すことが信頼になります。

数字から分かったこと

  1. 「鍵交換」まわりは安くて量がある。鍵開けの約5分の1の単価です。鍵をなくした後に交換を考える人も多く、元請けが狙う「緊急の鍵開け」とも重なりません。
  2. 「鍵屋＋地名」は安く、「鍵開け＋地名」は高い。「鍵屋 赤羽」は245〜1,061円、「鍵開け 板橋区」は1,643〜3,748円。同じ地域でも言葉で約3倍違います。
  3. 「緊急」「24時間」「深夜」は高い割に少ない。この言葉は元請けに任せます。「24時間・深夜も対応」は、サイトで安心してもらうための一言として使います。
  4. 「鍵屋」単体は量が多いが、合鍵作りや営業時間を調べる人も混ざる。地域を絞り、「合鍵」「営業時間」などには広告を出さない設定（除外キーワード）とセットで試します。
  5. 紛失の人は自分の状況で検索する。「家の鍵 なくした」「鍵が開かない」「締め出された」「鍵 なくした 賃貸」。これをサイトの見出しにそのまま使います。

※車・バイク・自転車・スーツケース・金庫の鍵は、今回は対象外にしています。

安否確認は「信頼」で取る

安否確認の鍵開けは単価が高く、需要も増えています。ただ、検索で鍵屋を探す人は少なく、取り方が紛失とは違います。

需要は増え続けている

  • 2024年に、自宅で亡くなった一人暮らしの人は全国で76,020人（警察庁）。約76%が65歳以上です。
  • 東京都は一人暮らしの世帯が全国で最も多く、約363万世帯（全世帯の約50%）です。
  • 全国の数字を世帯の割合で割り振ると、東京で一人暮らしの人が自宅で亡くなるのは月に約1,100人。入院や外出で連絡が取れないだけのケースも含めると、依頼の発生はこれより多くなります。

「安否確認で鍵屋を探す」検索は月数十回しかありません。家族はまず「警察にどう頼むか」を調べます。東京都で計測できた主な言葉を合計しても月170〜1,700回なので、検索と広告だけでは大きな件数になりません。

だから取り方はこうする

  • 大家・不動産屋・管理会社に直接案内する。繰り返し依頼が来る相手です。請求書払いと作業報告書で「任せて大丈夫」と思ってもらいます。
  • 警察との信頼を積む。警察からの依頼が元請け経由か直接かを確認し、直接なら対応の質で次につなげます。
  • サイトの記事の柱は「警察への頼み方と立ち会い」。一番検索される話題に正しく答え、鍵屋が必要になる場面から依頼につなげます。
  • 広告は少額で。安否確認の言葉は1クリック150〜343円と、紛失の約10分の1です。

サイトの入口

トップページは1つにして、開いてすぐの画面で2つのボタンに分けます。

鍵をなくした・開かない

  • ご本人が、今すぐ家に入りたいとき
  • 見出しの例：「家の鍵をなくした・家に入れない」「締め出された・オートロックで入れない」「賃貸でも大丈夫」
  • 料金表と「鍵交換の費用」も、ここから見られるようにする

家族・入居者と連絡が取れない

  • 家族・大家・管理会社・会社の総務が、安否確認を頼みたいとき
  • 警察への頼み方、立ち会い、料金の流れを先に説明する
  • 法人向けには請求書払い・作業報告書の案内を置く

進め方

  1. 最初の1か月
    0円でできることから

    元請けとの契約内容と手数料を確認する。Googleビジネスプロフィールを赤羽の自宅で登録する（住所は非表示）。依頼が来るたびに「日時・依頼者の種類・どうやって知ったか・結果・料金」を記録する。料金表、作業報告書、電話受付の流れを決める。

    費用 0円
  2. 1〜3か月目
    入口を作って、少額で試す

    サイトの作り直し（上の2つの入口）、作業事例のタイトルに地名を入れる、口コミのお願いを始める。北側だけの地域広告を「鍵交換」「鍵屋＋地名」で月3万〜5万円から試し、実際の1件の費用を測る。北側の不動産屋への案内を始める。

    広告費 月3万〜5万円
  3. 4〜6か月目
    元請けの手数料と比べて決める

    言葉ごとに「1件の費用」と「元請けの手数料」を比べ、得な言葉だけ広告を増やす。損な言葉はやめる。取引する不動産屋・管理会社を増やし、安否確認の記事（警察への頼み方）を書き始める。

  4. 7〜12か月目
    自社の割合を上げる

    マップの口コミと作業事例で北側の自社の依頼を増やす。取引している法人を増やし、安否確認の紹介先（特殊清掃・遺品整理・葬儀社・区の見守り制度）を作る。元請けの仕事は空いている時間で続ける。

サイトの記事は、公開から検索で評価されるまで3〜6か月かかるのが普通です。最初の半年は、マップと地域広告と直接の案内が中心になります。

友達に確認したいこと

元請けとの関係

  • 契約で禁止されていること（元請け経由のお客様への名刺・ステッカー配布、直接の受注、同じ地域での集客など）
  • 元請けに払う1件あたりの手数料（または1件の受け取り額）
  • 元請けから来る月の件数と、その内訳（鍵開け・鍵交換・安否確認）

安否確認

  • 警察からの依頼は元請け経由か、鍵マッハ24に直接か
  • 個人のお客様や警察が、どうやって鍵マッハ24を知ったか

料金と体制

  • 料金（鍵開け・鍵交換・安否確認）、深夜の割増、キャンセル料、支払い方法
  • 深夜の電話は誰が取っているか
  • 賠償責任保険に入っているか
  • 会社の正式名称と法人番号
