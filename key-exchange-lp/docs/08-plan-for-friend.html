鍵マッハ24（株式会社hgate）向け

鍵マッハ24 自社集客プラン

2026年10月作成。広告に頼りきらず、自社のサイトとGoogleマップから依頼が来る状態を作るための方針です。

結論

  1. 「鍵の紛失」だけで勝負するのは厳しい。検索の上位は大手チェーンと比較サイトが押さえていて、広告は1クリック1,000円を超える言葉もあります。紛失はやめるのではなく、Googleマップと作業事例で拾う「サブの柱」にします。
  2. メインの柱は「安否確認の鍵開け」。需要は増え続けているのに、専門で取り組む鍵屋がほぼいません。単価が高く、管理会社などから繰り返し依頼が来るので、月100件を目指せる分野です。
  3. 検索数を実測すると、安否確認は「検索で待つ」だけでは月100件に届かない。Googleのキーワードプランナーで調べたところ、安否確認まわりの検索は東京都で月数百回規模でした。そこで法人からの継続依頼と紹介で約8割、検索と広告で約2割を取る設計にします。記事や検索対策は、家族からの直接の依頼と、法人に信頼してもらうための土台として欠かせません。
  4. すべて業者に頼むと、1年目で約700万〜1,700万円。このプランは自分たちで進める前提なので、外注費はかかりません。必要なのは広告費とサーバー代、それと作業の時間です。

なぜ「鍵の紛失」一本では厳しいのか

紛失の依頼は数が多い一方で、ネット上の取り合いが最も激しい分野です。理由は4つあります。

1. 検索の上位を大手が押さえている

「鍵開け」「鍵 なくした」で上位に出るのは、ミツモア、くらしのマーケット、生活110番などの比較サイトと、鍵の110番救急車、鍵猿、アンロックなどの大手チェーンです。どこも何年も前から地域別のページと記事を大量に作っています。今から記事を書いても、この差は1〜2年では埋まりません。

2. 広告が高い

キーワードプランナーで東京都の1クリックの目安を調べると、「鍵開け」が617〜2,747円、「鍵 なくした」が499〜1,973円、「鍵開け 東京」は1,482〜3,980円でした。安否確認（150〜343円）の約10倍です。しかも大手は「4,400円から」「1,500円〜」のような安い入口価格で広告を出しています。

3. スマホでは広告とマップが先に出る

焦っている人はスマホで検索し、画面の上に出る広告か、その下のGoogleマップの3件に電話します。記事で検索1位を取っても、そこまで画面を下にスクロールしてもらえません。

4. Googleマップは住所で決まる

マップの順位は、登録した住所からの距離で大きく決まります。バーチャルオフィスの住所は登録できないので、赤羽の自宅を拠点に「出張型の業者」として登録します。この場合、マップで強く出られるのは赤羽を中心とした東京の北側（北区・板橋区・足立区など）が中心になります。

紛失はやめません。Googleマップ、作業事例の積み上げ、絞った広告、管理会社や駆けつけサービスとの提携で取ります。「記事で検索の上位を取りに行く」ことだけをやめる、という判断です。

なぜ「安否確認の鍵開け」なのか

鍵の紛失

  • 需要：とても大きい
  • 競合：大手・比較サイトが非常に強い
  • 単価：安値競争になりやすい
  • 繰り返しの依頼：ほぼない
  • 自然検索での勝ちやすさ：低い

安否確認の鍵開け

  • 需要：増え続けている
  • 競合：専門で取り組む鍵屋がほぼいない
  • 単価：高い
  • 繰り返しの依頼：管理会社などから継続して来る
  • 自然検索での勝ちやすさ：高い

需要は増え続けている

  • 2024年に、自宅で亡くなった一人暮らしの人は全国で76,020人（警察庁）。約76%が65歳以上です。
  • 死後8日以上たって見つかる「孤立死」の政府推計は、2024年21,856人、2025年22,222人と増えています。
  • 東京都は一人暮らしの世帯が全国で最も多く、約363万世帯（全世帯の約50%、全国の一人暮らし世帯の約17%）です。

全国の数字に東京の一人暮らし世帯の割合（約17%）をかけると、東京で一人暮らしの人が自宅で亡くなるのは年間約1.3万人、月に約1,100人という計算になります。安否確認の依頼は、亡くなっているケースだけでなく、入院や外出で連絡が取れないだけのケースも含むので、実際にはこれより多く発生しています。

※全国の数字を世帯の割合で按分した概算です。東京都の正式な統計ではありません。月100件は、この発生件数の1割未満にあたります。

競合はほぼ空いている

相手例弱いところ
鍵屋の安否確認ページスターキーロック、東京玄関鍵開け救急センター24（15,400円〜）ブログ1本やFAQの1項目程度。手順や警察との関係まで書いていない
駆けつけ代行（鍵屋ではない）マルチ救急24（日中13,200円・深夜17,600円）自分では鍵を開けられないので、開錠は別料金・別手配
見守りサービス大手セコム、ALSOK、日本郵便契約者しか使えない。突然「親と連絡が取れない」人には応えられない
比較サイトミツモア、くらしのマーケット安否確認に特化していない

実際の検索結果（「安否確認 鍵開け」、2026年10月にスマホで確認）

  • 広告：カギの110番と鍵のレスキューが出ているが、どちらも安否確認のことを一言も書いていない。「鍵開け」で広く出した広告がたまたま表示されているだけ。
  • 検索の上位4件：カギ本舗、レスキューなび、鍵のレスキュー、鍵猿。どれも全国展開の大手の「解説記事1本」で、専門のサービスページはない。
  • 「警察の立ち会いは必要か」で各社の説明が食い違っている。検索する人が一番知りたいことに、まだ誰もはっきり答えていない。
  • 「関連する質問」に関係ない質問が混ざっている（「オタク用語の鍵開けとは」など）。Googleがこのテーマの良い情報をまだそろえきれていない、というサインです。

数字から分かったこと

  1. 「安否確認で鍵屋を探す」検索は月数十回と少ない。鍵屋を指名して探す人は、まだほとんどいません。
  2. 一番多いのは「警察」まわりの検索。「安否確認 警察」だけで東京都で月100〜1,000回あります。家族はまず「警察にどう頼むか」を調べるので、記事の柱は「警察への頼み方と立ち会い」にします。上位の記事で、警察の立ち会いのもとで鍵屋が必要になる場面を正しく説明し、そこから依頼につなげます。
  3. 「無断欠勤」「入居者」「賃貸」など、会社や管理会社の検索も一定数ある。法人向けページの入口になります。
  4. 広告の単価は、安否確認が紛失のおよそ10分の1。競合が少ないためです。
  5. ただし検索の量そのものが小さい。東京都で計測できた主な言葉を合計しても、月170〜1,700回です。検索と広告だけで月100件は取れません。

月100件の作り方

検索数の実測をふまえて、法人からの継続依頼と紹介・提携で約8割、検索と広告で約2割を取る設計にします。安否確認は「検索で待つ」より「信頼関係で依頼が来る」分野です。記事やサイトは、法人が取引を決めるときの信頼の材料にもなります。

数字の考え方（試算）

  • 自然検索で10件：問い合わせの7割が作業になるとすると、月に約14件の問い合わせが必要です。ページを見た人の3%が問い合わせると考えると、月500人前後の訪問が目標です。「安否確認 警察」など警察まわりの記事で上位を取ることが前提になります。遠方に住む家族が、東京の親のことで検索するケースも入口になります。
  • 広告で10件：1クリック300円（「安否確認 鍵開け 費用」の上限）、クリックした人の8%が電話し、その7割が作業になるとすると、1件あたり約5,400円、月の広告費は約5.4万円です。必要なクリックは月180回ほどで、検索の量から見るとこれが上限に近い数字です。
  • 比べると：同じ計算で「鍵 なくした」（東京都、1クリック499〜1,973円）に広告を出すと、1件あたり約8,900〜35,200円かかります。

競合に勝つための約束

  1. 鍵屋が直接行く。駆けつけ代行と違い、開錠まで1回で済む。
  2. 都内各地に10数名が待機している。東京のどこでも早く着ける（実測した到着時間を載せる）。
  3. 警察とのやりとりに慣れている。何をすればいいか分からない家族に手順を案内できる。
  4. 料金を先に伝える。警察を待つ時間も含めた総額を、作業前に確定する。
  5. 開けた後まで任せられる。施錠、鍵交換、管理会社への報告まで対応する。
  6. 法人は請求書払い・作業報告書付き。

進め方

  1. 最初の1か月
    受け入れ体制を固める

    電話受付の台本、依頼者の権限確認の手順、警察との連携手順、法人向けの作業報告書、料金表、賠償責任保険、24時間の電話受付体制。法人は「この業者に任せて大丈夫か」をここで判断します。

  2. 1〜3か月目
    入口を作る

    サイトの作り直し、安否確認の専用ページと法人向けページの公開、記事10本、Googleマップ登録、広告の少額テスト、北側の管理会社から営業開始、区の見守り制度への参加。既存の作業事例39件のタイトルに地名を入れる。

  3. 4〜6か月目
    積み上げる

    記事を月6〜8本、作業事例は全件投稿、取引している法人を10社に、紹介・提携先を作る。

    目標 月30件
  4. 7〜12か月目
    広げる

    取引している法人を20〜30社に。検索で表示されている記事を書き直して強化する。

    目標 月60〜100件

記事は公開から評価されるまで3〜6か月かかるのが普通です。最初の半年は自然検索の数字がほとんど動かなくても、計画どおりです。
