## 1. 運用の全体像

| 頻度 | やること | 目安時間 | 効く先 |
| --- | --- | --- | --- |
| 毎日（作業のたび） | 作業写真を撮る・メモを残す（§3） | 2分 | 事例の素材 |

## 2. コラムの書き方

### 2-1. テーマの選び方
- [`02-keywords.md`](02-keywords.md) §8 の初期20本から順に書く
- 21本目以降は、**電話でお客様に聞かれたこと**をそのままテーマにする（「賃貸でも勝手に開けていいの？」など）。これが一番強いネタ

### 2-2. 記事の型（全記事共通）

```
タイトル：{検索キーワード}＋{何が分かるか}｜{屋号}
  例）鍵が回らない時の原因と対処法｜自分でできることと鍵屋に頼む目安｜{屋号}

h1（タイトルと同じ）
公開日・更新日・監修者

【結論ボックス】2〜3文で答えを言い切る        ← AIが引用するのはここ
目次

h2 原因・状況の説明（なぜそうなるか）
h2 自分でできる対処（手順を番号付きで）
h2 鍵屋に頼むべきケース
h2 費用の目安（自社の料金表と一致させる）
  ［記事内CTA］
h2 よくある質問（3〜4問）

監修者ボックス
関連記事（3本）
```

雛形：[`../src/column/kagi-nakushita/index.html`](../src/column/kagi-nakushita/index.html)（構造化データ・パンくず・CTA入り）

### 2-3. 書く時のルール
1. **見出しは質問形か、検索された言葉そのまま**にする（「鍵が回らない原因は？」）
2. **見出しの直後の1文で答える**。前置き（「鍵が回らないと困りますよね」）は書かない
3. **数字を入れる**（◯分、◯円、◯年、◯件）。曖昧な「すぐ」「お手頃」は使わない
4. **自分の経験を1つ以上入れる**（「先月◯◯で対応した現場では〜」）。AIや他社が書けない部分
5. 料金は**料金表ページと同じ数字**。変えたら全記事を検索して直す
6. 自分でできる対処は正直に書く（「鍵穴に潤滑油を差すのはNG、鍵穴専用スプレーを」など）。それで解決する人がいても、信頼が残り次の依頼や口コミにつながる
7. 他社の悪口・根拠のない「最安」「No.1」は書かない
8. 画像は自分で撮った写真。ファイル名とaltに内容を書く（`dimple-cylinder.webp` / alt「ディンプルシリンダーの鍵穴」）

### 2-4. 公開前チェック
- [ ] タイトル32字前後、検索キーワードが前半にある
- [ ] 結論ボックスだけ読んでも答えが分かる
- [ ] 料金が料金表と一致
- [ ] 記事内CTAと関連記事3本がある
- [ ] 公開日・更新日・監修者がある
- [ ] スマホで表示を確認した

## 3. 作業事例の投稿

### 3-1. 現場でやること（2分）
- 作業**前**と**後**の写真（鍵穴・ドア・新しいシリンダー）。**表札・部屋番号・顔・車のナンバーは写さない**
- メモ：日付／町名（番地は書かない）／建物種別／鍵の種類・メーカー／困りごと／到着時間／作業時間／金額
- 掲載許可をお客様に一言もらう（「個人が特定されない形で事例として載せてもいいですか？」）

### 3-2. 投稿の型

```
タイトル：{町名}の{建物種別}で{作業内容}｜{鍵の種類}

【作業データ】
エリア：{市区町村}{町名}
建物：マンション／アパート／戸建て
お困りごと：鍵をなくして家に入れない
鍵の種類：{メーカー}{型番}（ディンプルキー）
到着：お電話から◯分
作業時間：◯分
料金：◯◯円（税込・出張費込み）

【担当スタッフのコメント】（3〜5行）
どんな状況だったか／どう対応したか／同じことで困っている人へのアドバイス

写真：作業前・作業後
```

- 事例はエリア（市区町村）と作業種別で分類しておく → エリアページ・サービスページに自動で並ぶ（WordPressのカテゴリ／タグで実装）
- コメント欄が「その人にしか書けない一次情報」。ここを手抜きしない

## 4. Googleビジネスプロフィール（GBP）

- 屋号・住所・電話番号・営業時間を**サイトのフッターと一字一句同じ**にする
- カテゴリ：メイン「鍵屋」、サブで「錠前業者」等の該当するもの
- サービス一覧に料金表と同じ内容を登録
- 写真：スタッフ・作業車・作業風景を毎月追加
- 投稿：事例を週1で流用投稿
- 口コミには**全件返信**（悪い評価にも丁寧に）。返信にもエリア名や作業内容が自然に入るとよい

---

## 5. 口コミの集め方

- 作業完了・支払い後に、口コミ投稿用のQRコードを載せたカードを渡す
- 声かけ例：「もしよろしければ、Googleに一言いただけると、同じように困っている方の参考になります」
- **値引きや特典と引き換えにしない**（Googleのポリシー違反。景品表示法上のステルスマーケティング規制にも抵触するおそれ）
- サイトに掲載する口コミは、Google上の実際の口コミから許可を得て転載

## 6. 月次の振り返り（月1回・60分）

| 見る場所 | 見る数字 | アクション |
| --- | --- | --- |
| GA4 | 電話タップ数・LINEタップ数（`tel_click` / `line_click`、`cta_position`別） | どの位置のボタンが押されているか → 押されない位置は文言・デザイン見直し |
| コールトラッキング／着信履歴 | 実通話数・成約数 | タップ数と比べて通話数が少なければ、FVの番号や受付体制を確認 |
| Google広告 | 広告グループ別CPA・検索語句 | 無関係な語句を除外KWへ。CPAの良いグループに予算寄せ |
| Search Console | 表示回数が多く順位11〜30位の記事 | **リライト最優先**（結論ボックス強化・FAQ追加・事例追記） |
| Search Console | 想定外の検索語句で表示されている | 新しい記事テーマにする |
| GBP | 電話・ルート検索の数、口コミ数 | 口コミが月◯件未満なら声かけを徹底 |

料金を改定した月は、トップ・料金表・全記事・GBP・広告文・`script.js` の金額をまとめて更新する。
