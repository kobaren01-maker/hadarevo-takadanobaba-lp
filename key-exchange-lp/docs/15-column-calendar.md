# コラムの毎日投稿の計画 2026年10月30日

## 仕組み
- WordPressの「予約投稿」を使う。記事をまとめて書いて公開日時を設定しておけば、WordPressが毎日自動で公開する（パソコンやChromeが起動していなくてよい）
- 7本ずつ、各3,000字以上で書いて下書きに入れる → 監修者（友人）が確認 → サイト公開日の翌日から毎日1本ずつ公開されるよう予約
- 公開する時間は朝7時（通勤前に「鍵」を調べる人、前夜に困った人が読む時間）

## 品質の決まり（Googleの評価を落とさないために）
- Googleは、検索順位のために中身の薄い記事を大量に作ることを「スパム」として扱う。毎日投稿でも、1本ごとに検索した人の疑問に最後まで答える
- 1本に1つのテーマ。同じ内容の記事を言い方だけ変えて作らない
- 鍵マッハ24の現場の情報（作業事例、よくある相談、到着の実績）を必ず入れる。これはAIだけでは書けない部分で、友人に一言ずつもらうのが理想
- 監修者（代表）の名前を入れて、内容を確認してもらう
- 車・バイク・自転車・スーツケース・金庫の鍵は対象外
