# 大手鍵屋のLP分析と、取り入れる点 2026年10月28日

Googleで「鍵開け 東京」と検索し（2026年10月28日、Chrome）、広告の上位に出たLPと、検索結果の上位に出た地域ページを読んだ。
**文章・画像・デザインはそのまま使わない**（著作権の侵害になるおそれがある）。構成の考え方と、置いている要素を、鍵マッハ24の言葉と見た目で作り直して取り入れる。

## 各社の特徴
### カギ110番（広告用LP）
- 最初の画面：「最速5分で到着」を大きく。横に「到着後は最短5分で開錠」。その下に数字の丸バッジ3つ（1日の相談件数、到着スピードの評価など）
- 画面下に固定の帯：電話番号、24時間365日、無料メール相談ボタン
- 「鍵をなくした」「鍵を壊した」「鍵を閉じ込めた」「鍵が開かない」を絵で選ばせる
- 「安すぎる価格表示サイトにご注意ください」と、他社の安値表示への注意を自分から書く
- 料金は「出張費・作業費・部材費込みのコミコミ価格」と言い切る
- 選ばれる3つの強み、サービスの流れ（3ステップ）、よくある質問、東証上場・メディア掲載
- ほとんどが画像に文字を焼き込んだ作り（本文の文字は約2,800字だけ）

### 鍵の救急センター（広告用LP）
- スマホの縦長1列だけで作ったLP。本文の文字は170字ほどで、ほぼ全部が画像
- 最初の画面：「最短5分で即駆けつけ」、女性スタッフの写真、WEB限定クーポン
- 「鍵を開けたい」「違う鍵に交換したい」「鍵を新しく設置したい」「鍵を修理したい」を、アイコンと「◯◯円〜」の4つの箱で並べる
- 「こんなお悩みありませんか？」のチェックリスト → 「お任せください」
- 選ばれる3つの理由を、写真＋黄色のマーカーの見出し（「最短到着時間5分」など）で
- 電話ボタンを何度も繰り返す
- 「最安2,980円〜」と非常に安い入口の金額を出している

### ピース＆セキュリティ・ジャパン（鍵交換LP）
- 鍵交換を「価格重視」「コスパ重視」「防犯性重視」の3段階で、部品の写真と金額を並べる
- その下に「出張費等すべて込みの値段」「最長2年の無料保証」「対応エリア」の3つを小さく添える
- 電話番号の下に「東京・神奈川・埼玉・千葉総合窓口」

### カギの緊急隊（地域ページ・中央区）
- タイトル：「東京都中央区の鍵屋さん！鍵開け・鍵交換など…」。見出しの最初に区名
- 右上に「最新到着状況：◯分で到着！」
- 見積もり0円、カード決済、賠償保険に加入、部品交換の無料保証、大手不動産と業務提携、などを小さなバッジで並べる
- **区内の町名入りの施工事例**（【東京都中央区日本橋】鍵の交換がしたい など）
- 4つのステップの依頼の流れ
- **お客様の声に町名・駅名**（中央区新川、八丁堀駅周辺など）
- **地域の情報**：対応エリア、最寄りの駅、区の防犯対策の補助金（区役所の窓口と電話番号）、**区内の警察署・交番の住所**、近隣のエリア
- 右端に縦の「LINEでお問合せ」「メールでお問合せ」ボタン
- 構造化データ：WebPage、パンくず、Organization

### アンロック（トップ）
- 最初の画面：「鍵をなくした！鍵が開かない！」「開けられなければ0円 安心の明朗会計」、作業中の写真を丸く4枚
- 電話番号の帯の横に「メールでのお問合せ・お見積もり」
- 見出しの流れ：出張サービス → 料金 → 作業の流れ → **ご本人様確認について（本人確認書類として有効なもの）** → 作業事例 → 対応エリア → よくある質問 → 豆知識

## どの会社にもある「型」
1. 最初の画面に「到着の速さ」の数字を一番大きく
2. 画面下に固定の電話ボタン（スクロールしても常に見える）
3. 困りごとを絵で選ばせる入口
4. 信頼のバッジを横に並べる（保険、カード、見積もり、実績）
5. 選ばれる3つの理由（写真つき）
6. 依頼の流れを3〜4ステップで
7. 地名入りの事例とお客様の声
8. 電話のほかに、メールやLINEの入口

## 取り入れる点（優先順）
| 優先 | 取り入れること | 下書きでの作り方 |
| --- | --- | --- |
| 1 | **画面下に固定の電話の帯** | 全ページの最後に帯を置き、CSSで画面下に固定。「24時間受付・最短5分」と電話番号 |
| 2 | **困りごとを絵で選ぶ入口** | 「鍵をなくした」「締め出された」「鍵が開かない・回らない」「鍵が折れた」「鍵を交換したい」「家族と連絡が取れない」を、簡単な線の絵（自作の図形）つきの箱にして、各ページへ |
| 3 | **数字を大きく見せる信頼のバッジ** | 「最短5分」「年間3,000件以上」「10名以上が24時間待機」「賠償責任保険に加入」を、数字を大きくした4つの箱に |
| 4 | **「安すぎる表示に注意」の囲み** | 東京都消費生活総合センターの注意喚起を出典にして、「◯◯円〜の安い広告に注意。鍵マッハ24は作業前に書面で総額」と書く。他社の名前は出さない |
| 5 | **鍵交換の3段階の選び方** | 「費用を抑える」「バランス」「防犯性を高める」の3つの箱（金額は正式な料金が決まってから） |
| 6 | **お客様の声に町名** | 既存の作業事例にある「お客様ご感想」（本物）を、町名つきで各ページと地域ページに抜粋して載せる。口コミの構造化データ（Review）は付けない（自社サイトの口コミはGoogleの対象外） |
| 7 | **地域ページに地域の情報** | 区内の警察署（安否確認に関係する）、主な駅、近隣の区。数字や住所は公式の情報で確認してから載せる |
| 8 | **本人確認書類の一覧** | 顔写真付きの身分証の例、持っていないときの代わりの書類（友人の回答どおり） |
| 9 | **メールでの相談の入口** | 既存の「お問い合わせ」ページへのボタンを、電話の横に小さく。LINEは公式アカウントができてから |

## 下書きへの反映（2026年10月28日）
- 1〜6を `wordpress/site-builder.js` と `new-top.css` に入れ、WordPressの下書き17件を更新した
  - 1 固定の電話の帯：全ページ・全コラムの画面下（電話＋「メールで相談」→既存のお問い合わせページ）
  - 2 絵で選ぶ入口：トップ、鍵をなくした（6つの箱。絵は線だけの自作）
  - 3 数字のバッジ：トップ、鍵をなくした、鍵交換、安否確認、地域ページ
  - 4 安すぎる表示への注意：トップ、鍵をなくした、鍵交換、料金表
  - 5 鍵交換の3段階：鍵交換（金額は「◯◯円〜」のまま）
  - 6 お客様の声：トップ、鍵をなくした、地域ページ（作業事例の「ご感想」から自動で抜粋）
- スマホ幅（375ピクセル）で横のはみ出しがないことを確認
- 7〜9も反映（同日）
  - 7 地域の情報：6つの地域ページに「主な駅」「管轄する警察署（警視庁の『所在地から探す』で確認）と警視庁のページへのリンク」「近くの地域（地域ページがある区はリンク）」。区の防犯補助金は、内容を区のサイトで確かめられていないので入れていない
  - 8 本人確認に使える書類：鍵をなくした、安否確認（運転免許証・マイナンバーカード・パスポート・在留カード。ない場合は不動産の契約書・公共料金の支払い書など）
  - 9 メール相談：画面下の帯に加え、各ページ最後の囲みに「お問い合わせフォーム」へのリンク

## デザイン第2版（2026年10月28日）
「AIが作ったページに見える」という指摘を受けて、競合に共通する見せ方に寄せて作り直した（`wordpress/new-top.css` を全面的に書き直し）。
- 最初の画面：濃い紺の帯（斜めの細い線の模様）、白い太字の見出し、「最短5分」を黄色で大きく、白い入口ボタン（左に色の線と矢印）
- 電話ボタン：オレンジの立体ボタン、左に電話の絵、最初の画面ではゆっくり脈打つ（動きを減らす設定の人には動かさない）
- 本物の現場写真：WordPressに入っている作業事例の写真（個人情報はモザイク済み）を、最初の画面に3枚、「ご依頼の多い作業」の箱、作業事例の一覧に使用
- 見出しは太く中央寄せで、下にオレンジの短い線。小見出しは左に紺の線
- 「3つの約束」は上にオレンジの線と「約束1〜3」の大きな箱、流れは「STEP1〜」と下向きの矢印
- 料金は赤の太字、表は1行おきに色
- よくある質問は「Q」「A」の丸、お客様の声は人の絵つきの吹き出し、鍵交換の3段階は真ん中を「いちばん人気」として強調
- 安すぎる広告への注意は、赤い「!」の丸と黄色の囲み
- 章によって薄い色の帯で区切る（約束、お客様の声、よくある質問）
- 文字は Noto Sans JP の太字（Googleのフォント）
- テーマの見出し帯の色を紺にそろえた
- スマホで画面下の電話番号が2行に折れないように調整

## 取り入れない点
- **「2,980円〜」「8,800円〜」のような安い入口の金額。** 東京都消費生活総合センターが注意を呼びかけている見せ方で、実際の請求との差が苦情の元になる。鍵マッハ24は作業前に書面で総額を出すことを強みにする
- **WEB限定クーポン、アンケート割引。** 値引きの見せ方は安値表示と同じ印象になる
- **「開けられなければ0円」。** 鍵マッハ24はお客様都合のキャンセルにキャンセル料があるため、書くと食い違う
- **文字を画像に焼き込む作り。** Googleが文字を読めず、検索に弱い。修正もしにくい
- **素材写真のモデル。** スタッフの写真が使えるようになったら本物を使う（顔写真は友人の回答で一旦保留）
- **「日本全国対応」。** 鍵マッハ24の対応エリアに合わせて、東京都と埼玉県南部で書く
- **区の名所や神社の紹介のような、鍵と関係のない文章。** 地域ページの文字数を増やすためだけの文章は評価されにくい
