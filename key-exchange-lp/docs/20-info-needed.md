# ページの精度を上げるために友人からもらう情報 2026年11月6日

下書きに残っている空欄（◯◯円・【要確認】）と、書いてあるが本人に確かめていない事実、ページを強くする材料を、優先順にまとめた。
友人に送る文面は、このまま貼り付けて使える。

## A. 公開に必ず必要（これがないと公開できない）

### 1. 料金（税込）
- 鍵開け：玄関の一般的な鍵／ディンプルキーなど防犯性の高い鍵／補助錠・室内ドア
- 鍵交換（部品込み）：一般的なシリンダー／ディンプルシリンダー／補助錠の取り付け
- 鍵の修理（回らない・抜けない・折れた鍵の取り出し）
- 安否確認の鍵開け／開けたあとの施錠・鍵交換
- 鍵交換の3つのプランそれぞれの「◯◯円〜」（費用を抑える／バランス／防犯性を高める）
→ 「◯円」か「◯円〜」かも教えてほしい。スタッフによって金額がばらばらと聞いているので、サイトに載せる「会社として決めた金額」が必要

### 2. 追加でかかる費用
- 出張費：料金に含む／別に◯円
- 見積もり費：無料／◯円
- 深夜・早朝の割増：なし／あり（何時から何時、◯円）
- キャンセル料：◯円（いつからかかるか。到着後？作業前？）
- 警察の到着を待つ間の料金：無料／◯分ごとに◯円

### 3. 鍵交換にかかる時間
- 一般的な玄関の鍵で、だいたい何分か
- 部品の在庫を車に積んでいて、その日に交換できることが多いか

### 4. 法人との取引の始め方
- 契約書は必要か、最初に何をしてもらうか（電話だけでよい？書類を交わす？）
- 請求書の締め日と支払い期限
- 適格請求書（インボイス）の登録番号はあるか（法人は必ず気にする）

## C. ページを強くする材料（なくても公開できるが、あると順位と電話が増える）

### 代表・会社のこと（Googleは「誰がやっているか」を重視する）
- 鍵の仕事の経験年数、これまでの件数、始めたきっかけを2〜3行
- 代表の顔写真（保留中。出せるなら効果が大きい）
- 管理会社・不動産会社との取引のおおよその数（社名は出さない）
- 安否確認の鍵開けの、年間のおおよその件数

### 現場の話（コラムの「鍵マッハ24の現場から」の欄を本物にする）
- よくある相談トップ3（例：酔って鍵をなくした、オートロックで締め出し、など）
- 夜中に多い依頼、季節で増える依頼
- 印象に残っている現場の話を1〜2件（個人が分からない形で）
- お客様によく聞かれる質問と、いつもの答え

### 写真
- スタッフの作業中の写真（顔なし・手元だけでよい）：電話、到着、見積もり、作業、支払いの5場面。今は仮の写真
- 作業着・車・道具の写真

### 作業事例（毎週1〜2件。Googleドライブで1件1フォルダ）
1件ごとに、次をメモで入れてもらう：
- 日付／地域（区と町名まで）／建物（戸建て・マンション・アパート）
- 依頼の内容（例：鍵をなくして入れない）
- 鍵の種類・メーカー（分かれば）
- 作業の内容と、かかった時間／到着までの時間
- お客様のひとこと（いただけた場合）
- 写真：作業前と作業後（表札・部屋番号・顔・車のナンバーは写さない）
- 料金（載せてよい場合だけ）
とくに足りない地域：板橋区・豊島区・練馬区・荒川区・文京区・台東区・川口市・戸田市。ここの事例が増えると、その地域のページを作れる
