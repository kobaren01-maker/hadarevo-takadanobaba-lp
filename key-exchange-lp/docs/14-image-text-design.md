# 見やすさを最優先にした作り直し：画像とテキストの仕分け 2026年10月30日

## 前提
- 来る人のほとんどは緊急。スマホで、焦りながら、数秒で「ここに電話していいか」を決める
- だから、最初の画面で読ませるものを減らし、迷わず電話できることを最優先にする
- 一方で、Googleは画像の中の文字をほとんど読まない。検索で見つけてもらうための情報は、必ずテキストで書く

## 仕分けの決まり
1. **画像にするのは「一瞬で伝わればよいもの」だけ。** 背景、絵（アイコン）、印、本物の現場写真
2. **画像の中に文字を入れる場合は飾りだけ。** 同じ意味を、必ず近くにテキストでも書く
3. **電話番号・料金・地名・手順・質問と答えは、絶対に画像にしない。** 押せない・読めない・Googleに伝わらない

## 仕分け表
| 部品 | 形 | 理由 |
| --- | --- | --- |
| 最初の画面の背景 | **画像**（本物の現場写真を暗く重ねたもの） | 雰囲気だけ伝われば十分。文字は上にテキストで重ねる |
| 「最短5分」の丸い印 | **画像**（飾り）＋同じ言葉を見出しにテキストで | 目に飛び込む印。意味は見出しで伝える |
| 困りごとの絵 | **画像**（線の絵）＋名前はテキスト | 絵で選べると読まずに済む。名前はGoogleにも伝わる |
| 依頼の流れの絵 | **画像**（電話・車・書類・工具・確認・支払いの絵）＋説明はテキスト | 絵で流れがつかめる。説明は検索に効く |
| 約束の絵 | **画像**（書類・円・虫めがね）＋文章はテキスト | 同上 |
| 現場写真 | **画像**（作業事例の本物の写真） | 本物であることが一目で伝わる |
| ロゴ | **画像** | ブランドの印。会社名はテキストでも書く |
| ページの見出し（h1・h2） | **テキスト** | Googleが「何のページか」を判断する一番の材料 |
| 結論の文 | **テキスト** | 検索結果やAIの答えに引用される |
| 電話番号 | **テキスト**（押すと電話がかかる） | 画像だと押せない |
| 料金表 | **テキスト** | 「鍵開け 料金」で探す人とGoogleに必要 |
| 対応エリア・地名・駅・警察署 | **テキスト** | 「◯◯区 鍵屋」の検索に効く |
| 依頼の流れ・約束の文章 | **テキスト** | 安心材料。検索にも効く |
| よくある質問 | **テキスト** | Googleが質問と答えとして読む（構造化データあり） |
| 作業事例・お客様の声 | **テキスト**＋写真 | 地名と作業内容が検索の入口になる |
| 会社名・住所・電話（フッター） | **テキスト** | Googleマップとそろえる情報 |

## 最初の画面（スマホで最初に見える範囲）に置くもの
1. どこで何をする店か：「東京都内・埼玉県南部｜24時間受付」
2. 見出し：「鍵開け・鍵交換 最短5分で駆けつけ」（「鍵開け」「鍵交換」が検索に効く）
3. 電話ボタン（オレンジ、いちばん大きく）
4. 安心の印を3つだけ：作業前に書面でお見積もり／24時間365日／賠償責任保険
5. 安否確認の人への小さな入口：「家族・入居者と連絡が取れない方はこちら」

それ以外（数字のバッジ、現場写真、2つの大きな入口ボタン）は、最初の画面から外して下へ回す。

## ページの順番（トップ）
1. 最初の画面
2. どんなお困りですか？（絵で選ぶ6つ）
3. 料金の目安（3行だけ）＋安すぎる広告への注意（短く）
4. ご依頼の流れ（絵つき4ステップ）
5. 安心してお任せいただくための3つの約束（絵つき）
6. 選ばれる理由（数字のバッジ＋現場写真）
7. 最近の作業事例（写真つき）
8. お客様の声
9. 対応エリア
10. よくある質問
11. 鍵のお役立ちコラム
12. 最後の電話

## 見やすさの決まり（認知負荷を下げる）
- 電話ボタンのオレンジ以外に、目立つ色を使わない（注意の囲みだけ例外）
- 1つの箱に書くのは、太字の1行と、短い説明1〜2行まで
- 文字はスマホで16px以上。説明文は1文を短く
- 枠線を減らし、薄い背景色で区切る
- 画面下の電話の帯は常に出す

## 反映したこと（2026年10月30日、WordPressの下書き17件）
- 最初の画面：本物の現場写真をぼかして紺を重ねた背景画像（`wordpress/fv-bg-2.webp` → メディア「kagimach24-fv-bg.webp」）、見出し「鍵開け・鍵交換 最短5分で駆けつけ」、電話ボタン、安心の印3つ、安否確認への小さな入口だけにした。右上に「最短5分」の丸い印（飾りのSVG。読み上げ対象外）
- 2つの大きな入口ボタン・数字のバッジ・現場写真は、最初の画面から外した。数字と写真は「選ばれる理由」へ
- トップの「ご依頼の多い作業」（写真つきの箱）は、「どんなお困りですか？」と重なるので外した
- 依頼の流れ：5ステップを「太字1行＋説明1行」にし、電話・車・書類・ペン・財布の絵（CSSの画像）を付けた。キャンセル料の説明は流れの下に1行で
- 3つの約束：文章を短くし、書類・盾・虫めがねの絵を右上に
- 安すぎる広告への注意：2文に短くした
- 枠線を減らし、影と薄い背景色で区切った。文字は16px
- 背景画像のアップロードは、最初のWebPがサーバーの防御機能に止められたため、画質を変えたWebPで入れ直した

## 残っている課題
- トップ案の下書きの名前（「新トップ案（2つの入口）」）は、管理画面で探しやすいように残している。公開してトップに設定するときに、ページの名前を「鍵マッハ24」などに変える
- スタッフの写真が使えるようになったら、最初の画面の背景を「作業中のスタッフ」の写真に替えると、さらに伝わりやすい
