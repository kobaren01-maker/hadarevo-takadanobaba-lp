## 7. 広告（リスティング）用のグループ案

| 広告グループ | 主なKW（フレーズ／完全一致） | FV見出しの出し分け（フェーズ2） |
| --- | --- | --- |
| 紛失・閉め出し | 鍵 なくした／鍵 紛失／家 入れない | 「鍵をなくして入れない方へ」 |
| 鍵開け | 鍵開け／鍵屋 近く／鍵開け 24時間 | 「玄関の鍵開け 最短◯分」 |
| 鍵交換 | 鍵交換／シリンダー交換 | 「鍵交換 部品・工事込みで◯円〜」 |
| 車 | 車 鍵 なくした／インロック／スマートキー 作成 | 「車の鍵トラブル その場で対応」 |
| 地域 | {地域} 鍵屋／{地域} 鍵開け | 「{地域}まで最短◯分」 |

- 除外KW：自分で／DIY／求人／バイト／ゲーム名・作品名の「鍵」 など
- 広告文にも「総額」「キャンセル無料」「到着◯分」を必ず入れ、LPの表記と一致させる（不一致は品質スコアと信頼の両方を落とす）
