# 検索対策を徹底した新サイトの構成 2026年10月27日

WordPress（h-gate.jp）に、すべて**下書き**で作成済み。公開中のページ・投稿は変えていない。
作り方の元：`key-exchange-lp/wordpress/site-builder.js`（ページの中身）と `new-top.css`（デザイン）。

## 考え方
1. **1つの言葉に、1枚の専用ページ。** Googleはページ1枚ごとに「何のページか」を判断して順位を付けるので、紛失・鍵交換・安否確認・料金・地域を別々のページにした
2. **ページの最初に答えを書く。** 各ページの冒頭に「結論」の箱を置いた。Googleの検索結果やAIの答えに引用されやすい書き方
3. **本物の作業事例を使う。** 既存の投稿39件から、地域・内容ごとに自動で一覧を作って各ページに差し込んだ。作り話の口コミや数字は書かない
4. **ページどうしをつなぐ。** すべてのページから、サービス・料金・地域・コラムへリンクしている
5. **Googleに伝える情報（構造化データ）を全ページに入れる。** 鍵屋であること（Locksmith）、サービス内容（Service）、よくある質問（FAQPage）
6. **地域ページは実績のある区だけ。** 事例のない地域のページを量産すると、中身の薄いページとして評価が下がるため

## 確認したこと（2026年10月27日、プレビューで）
- 全ページでタイトル25〜34字、説明文87〜105字
- 構造化データが正しく読めること（トップ：Locksmith＋WebSite、サービス：Service＋FAQPage、地域：Service、コラム：テーマが出すArticle）
- パンくず（「HOME / 対応エリア / 江東区…」の道しるべ）の構造化データはテーマが出している
- スマホ幅（390ピクセル）で横にはみ出さない
- サイトマップ（/wp-sitemap.xml）とrobots.txtは動いている。公開すれば自動で載る

## つまずいた点
- サーバーの防御機能（WAF）が、①CSSのコメント「/* */」、②長い本文つきの新規作成、を攻撃と見なして止める。スクリプトで①コメントを外す、②空の下書きを作ってから本文を入れる、の2つで回避している

## 「究極」に持っていくために、残っていること
### 友人の情報が必要（これがないと上位は取れない）
- 料金（◯◯円）、深夜割増、支払い方法、到着目安、必要書類 → 下書きの赤字【要確認】
- 監修者（代表の氏名・経歴・資格）と会社の正式名称 → 「誰が書いたか」はGoogleが重視する
- 実際の写真（スタッフ、作業車、作業中の手元）→ 本物の写真は強い信頼材料
- 作業事例の場所が「埼玉県」「記載なし」のものは市町村名。大阪府の事例（ID 533）は本当に自社の作業か

### ユーザーの判断が必要（公開サイトが変わる）
- 下書きを公開し、トップ（今のHOME、ID 13）を新トップ案に差し替える
- 事例をカテゴリー「作業事例」に移す
- メニュー（ホーム／会社概要／ブログ）を、サービス・料金・対応エリア・コラムに変える
- サイト名「鍵トラブル即対応｜鍵マッハ24」を「鍵マッハ24」にするか（検索結果のタイトルの末尾に毎回付くため）

### 公開後にやること
- Googleサーチコンソール（Googleでの表示回数や順位が分かる無料の管理画面）に登録し、サイトマップを送る
- Googleビジネスプロフィールを登録し、ホームページと店名・電話番号をそろえる
- 作業事例を毎週1件以上、地名入りのタイトルで追加する（地域ページに自動で増える）
- コラムを月に数本追加する（「警察 安否確認 立会い」「オートロック 締め出し」など、09の言葉から）
- 口コミをお願いする（Googleマップ）
